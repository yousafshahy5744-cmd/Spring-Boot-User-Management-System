
# User Management System

A Spring Boot based User Management System.

## Overview
This project provides user registration, login and user management functionality using Spring Boot and Spring Security.

## Technologies Used
- Java 21
- Spring Boot
- Spring Data JPA
- Spring Security
- MySQL
- JWT Authentication
- Maven

## Features
- User Registration
- User Login
- Password Encryption
- JWT Authentication
- User Management
- JPA Repository Operations

## Project Structure
- controller
- service
- repository
- model
- config
- security

## Database Setup
1. Create a MySQL database.
2. Configure database credentials.
3. Execute the SQL file located in `src/main/resources/db/`.

## How to Run
1. Clone this repository.
2. Open the project in IntelliJ IDEA.
3. Configure MySQL.
4. Run the Spring Boot application.
